## Summary

Edge banding is the process of applying a thin strip of material to the exposed edges of panel materials to conceal the core and provide a finished appearance. Dawin Finishes uses hot-melt adhesive application via a dedicated edge bander machine.

## Methods

### Machine Edge Banding (Primary)
- **Equipment:** Automatic edge bander with pre-milling, gluing, trimming, scraping, and buffing stations
- **Materials:** PVC tape (0.4mm and 2mm), ABS tape, melamine tape
- **Adhesive:** EVA hot-melt (standard) or PUR (moisture-resistant applications)
- **Speed:** 8–12m/min depending on material thickness

### Hand-Applied Edge Banding (Backup)
- **When:** Short runs, curved edges, site work
- **Method:** Iron-on melamine tape or contact adhesive with PVC
- **Trim:** Router with flush-trim bit or hand trimmer
- **Quality:** Acceptable but not as consistent as machine application

## Edge Selection Rules

| Application | Edge Type | Thickness |
|-------------|-----------|-----------|
| Concealed edges (backs, undersides) | PVC | 0.4mm |
| Visible carcass edges (fronts) | PVC | 0.4mm |
| Door edges (all 4 sides) | PVC | 2.0mm |
| Worktop edges | PVC or ABS | 2.0mm |
| Solid timber effect | Solid lipping | 3–5mm |
