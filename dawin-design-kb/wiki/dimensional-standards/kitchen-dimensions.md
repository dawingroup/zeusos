## Summary

Standard kitchen dimensions used in Ugandan installations. Based on a 870mm worktop height (720mm carcass + 150mm adjustable legs). Wall units mounted at 1350mm from floor (600mm splash back clearance above 870mm worktop, minus wall unit overlap). These are defaults — individual kitchens may vary based on client height preferences and site conditions.

## Key Relationships

- Worktop height = carcass height + leg height = 720 + 150 = 870mm
- Wall unit bottom = worktop height + splash back = 870 + 600 - 120 = 1350mm
- Available splash back = wall unit bottom - worktop height = 1350 - 870 = 480mm (visible)
- Tall unit height should align with wall unit top = wall unit bottom + wall unit height = 1350 + 720 = 2070mm (rounded to 2100mm)
